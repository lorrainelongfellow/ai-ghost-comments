# AI 幽灵注释

在 VS Code 的源代码行尾显示 Gemini 生成的中文解释。悬停可查看完整注释。

## 安装和使用

1. 按下方步骤从源码生成 VSIX。在桌面版 VS Code 1.90 或以上打开扩展面板，从菜单选择 **从 VSIX 安装**，选中生成的 `ai-ghost-comments-0.5.4.vsix`。
2. 在终端运行 `agy`，确认 Antigravity CLI 已登录你的 Google 账号。扩展复用本机登录。若自动查找不到，可在插件侧栏的 Antigravity CLI 设置中选择或填写路径。
3. 打开代码，按 `Alt + G`（macOS 用 `Cmd + Option + G`）。扩展从当前屏幕所在的批次开始，逐批显示当前文件的行尾注释。
4. 再按一次隐藏。当前批次完成后暂停，重新显示时继续剩余批次。已完成的注释保存在本机，切换标签页、重新打开或重启 VS Code 后都能复用。重启后会自动恢复上次显示的注释，主动隐藏的文件会记住隐藏状态。自动恢复只读本机缓存，缺失的批次在手动显示时生成。
5. 点击活动栏的 **AI 幽灵注释** 图标，或运行 `AI 幽灵注释: 打开设置`。可在侧栏选择模型、自动恢复和注释密度。切换「逐行／关键逻辑」会即时更新当前显示。
6. 在代码里把光标放进函数，或选中要解释的代码，再点击 **注释当前函数** 或 **注释选区**。当前函数由 VS Code 已安装的语言扩展识别。悬停注释可以点击标识符，查询并跳转到语言扩展提供的定义。
7. 注释缓存按模型、函数和代码块复用。编辑文件后会恢复仍能匹配的本地注释。点 **补齐注释** 生成缺失部分，点 **重新生成全文** 刷新全部注释。

## 请求范围

- 分批发送所选范围内需要生成注释的非空行。每批最多 80 行，通常不超过 16,000 个源码字符，超长的单行独立请求。
- 注释生成请求会等待模型返回。XHigh 每次最多请求 24 行。每段成功后立即显示并保存。生成中断后可点 **补齐注释** 从剩余行继续。
- 返回格式异常时，会用当前模型缩小请求并重试。
- 注释生成由快捷键、命令或侧栏按钮触发。Antigravity CLI 将待注释的代码和行号发送给选定的模型。打开设置侧栏时会查询账号可用的模型列表。结果保存在本机，并通过编辑器装饰显示。
- 默认使用 Antigravity CLI 中已选的模型。可在 `aiGhostComments.model` 填写 `agy models` 列出的模型 ID。账号权限和用量由 Antigravity CLI 提供。
- 提示词要求根据源码片段解释行为。类型、单位和保护条件仍以实际源码为准。

[Antigravity CLI 无界面模式](https://antigravity.google/docs/cli/headless/)

## 从源码打包

需要 Node.js 22 或以上及 npm。

```sh
git clone https://github.com/lorrainelongfellow/ai-ghost-comments.git
cd ai-ghost-comments
npm run check
npm run package
```

VSIX 安装包生成在项目根目录。在 Windows PowerShell 中也可以用 `npm.cmd` 运行上述 npm 命令。
